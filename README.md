# MAH-LLB CET 2027 Sales Website

Static HTML/CSS/JS landing page for selling the digital guide.

## Before launch
1. Open `script.js`.
2. Replace `PASTE_YOUR_CHECKOUT_LINK_HERE` with your live payment/checkout URL.
3. Replace the sample page with selected real pages from your book if desired.
4. Test the checkout on mobile and desktop.
5. Add your support email/WhatsApp only if you are prepared to handle customer support.

The site intentionally does not pretend to be affiliated with Maharashtra State CET Cell.
